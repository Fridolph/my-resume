# 03 · AI 能力与迁移清理计划

> 本文记录 rs-admin 计划集成的 **AI 功能清单**、各功能的**归属端**，以及旧体系到 rs 系列的**迁移与清理计划**。

## 1. AI 集成功能清单

rs-admin 作为业务聚集点，将逐步集成以下能力：

| 功能 | 说明 |
|---|---|
| 对话后帮改简历 | 与 AI 对话后，由 AI 协助修改简历内容 |
| 找工作简历分析 | 面向求职场景，分析简历（匹配度、亮点、改进点等） |
| 模拟面试 / 答题 | 面试模拟与题目作答（**归属“找工作模块”，后续加入**） |
| 文档导入快速填写 | 通过导入 **md / word / pdf / text** 快速帮助填写与优化字段（**结果写入数据库**） |

> “找工作模块”为**后续范围**，当前里程碑不含；此处仅登记方向，避免提前混入。

## 2. 各功能的归属端

- **rs-admin**：功能的**触发/操作入口**（业务聚集点）。
- **rs-api**：承载**功能与逻辑**（AI 调用编排、数据处理、写库）。
- **rs-web**：**仅**保留 AI 对话（对访客），不承载上述业务型 AI 功能。

```
rs-admin（触发） ──► rs-api（逻辑/写库）
rs-web（仅对话）──► rs-api
```

## 3. 迁移与清理计划

- **触发时机**：重构完成并**发布后**。
- **动作**：删除旧 `docs/` 与 `admin / web / api` 目录，**统一使用** `rs-admin` / `rs-web` / `rs-api`。
- **原则**：
  - 迁移**渐进、可回滚**，避免一次性铺满。
  - 旧体系在删除前保持可用，作为对照与回退基线。
  - 相关文档随重构回填本目录（`docs/rs/`）。
